# Additional analyses and research opportunities

These materials are separate from the reconstructed original manuscript.
Run `make extensions` from the repository root to rebuild the ANES panel and
2012 advertising experiment outputs in `tabs/` and `figs/` here. Inputs are
verified against `sources.csv`; respondent-level outputs remain ignored under
`data/derived/` at the repository root.

- [Methods](docs/methods.md)
- [Research design and the archived experiment](docs/research-design.md)
- [Recent literature](docs/literature.md)
- [Additional data opportunities](docs/data-extension.md)

Candidate-versus-party panel comparisons are descriptive. The experiment
exports report both negative-minus-positive and negative-minus-control
comparisons with uncertainty, separately for absolute candidate and party
gaps. The larger export contains completed cases, not every assigned case;
assignment and selection documentation are needed to establish the analysis
population. An interval containing zero does not establish equivalence.

Later-data and literature opportunities should be evaluated for their
contribution before incorporation into a second manuscript version.
